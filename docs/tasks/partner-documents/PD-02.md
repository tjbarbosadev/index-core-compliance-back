## Objetivo

Cliente Mega no admin-api (vault HTTP e/ou MEGAcmd), pasta `partner-docs/{partnerId}/{cpfCnpj}`, **sem** nextcorefim. Env no `lib/env.ts`.

## Definição de pronto

- `uploadPartnerFile` / `downloadPartnerFile` / `deletePartnerFile` exportados.
- `megaConfigured()` false → upload lança erro mapeável a 503.
- Vault: `system=opcore`, `folder=partner-docs/{partnerId}/{cpfCnpj}`, nome `{fileId}__{safeName}`.
- Testes unitários com `fetch`/cmd mockados (sucesso + 502).
- Sem dependência de `NEXTCOREFIM_*`.

## Dependências

Nenhuma (paralelo com PD-01).
